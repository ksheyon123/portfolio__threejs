# 정점으로 면 만들기 — 3D 수동 면 정의 (Vertex → Face, 3D)

## 목적
2D 데모(`feat/vertex-face`, `/vertex-face`)는 평면 위 점만 찍으면 **들로네가 면 연결(index)을 자동으로** 정해줬다.
하지만 3D 공간에 흩어진 정점은 "어느 3개가 한 면인가"가 **자동으로 정해지지 않는다** — 같은 점 8개라도
정육면체가 될 수도, 전혀 다른 껍데기가 될 수도 있다. 그래서 이 데모는 사용자가 **정점 3개를 직접 골라
삼각형 면을 정의**한다. `index` 버퍼를 사람이 손으로 채우는 셈이며, 이것이 spec 목적문
"어느 정점 3개가 한 삼각형 면을 이루는가"의 정직한 3D 일반화다. 오목·비볼록 도형까지 만들 수 있다.

2D 데모가 "position 버퍼는 손으로, index는 알고리즘이 자동"이었다면, 이 데모는 **position·index를 모두 손으로** 채운다.

## 범위
- `/vertex-face-3d` **별도 라우트 + 별도 페이지 컴포넌트**(`VertexFace3D.tsx`)로 만든다. 기존 페이지·모델(`VertexFace`·`FaceMesh`·`delaunay.ts`)은 **건드리지 않는다**.
- 면 생성 로직은 기존 `src/models/` 패턴대로 클래스(`FaceMesh3D`)로 분리한다.
- **면은 수동**: 사용자가 정점 3개를 골라야 삼각형 면이 생긴다. 자동 삼각분할(들로네)은 이 데모에 없다.
- **정점 배치는 다중 작업 평면 스냅**: 바닥(`y=0`)·앞(`z=0`)·옆(`x=0`) 세 작업 평면 중 **활성 평면 위에만** 정점을 찍는다. 임의 깊이를 한 번의 클릭으로 정하는 문제를, 활성 평면으로 깊이를 고정해 푼다.
- 작업 평면 정의·정점 스냅 계산은 Three.js 수학 객체(`Plane`·`Ray`)를 쓰지만 씬/렌더러에 의존하지 않는 순수 계산이므로 **`src/models/workPlane.ts`** 로 분리해 `FaceMesh3D`/페이지가 호출한다. (2D의 `@libs/delaunay`는 Three 무의존이라 `@libs`에 뒀지만, 이건 THREE에 의존하므로 `src/models/`에 둔다.)
- **범위 밖**: 자동 표면 재구성(볼록 껍질·ball-pivoting 등), 면의 사각형/n각형 지원(삼각형만), 정점 스냅(격자 눈금 맞춤), undo/redo. 향후 확장.

## 기능 목록

### 기능: 3D 정점 목록 → position 버퍼
- **의도**: 2D와 달리 정점이 3성분(x, y, z)을 온전히 쓴다. 좌표 목록을 GPU가 읽는 `position` attribute로 변환한다.
- **방식**: `FaceMesh3D`가 정점 배열(`Vertex3D {x, y, z}[]`)을 보관한다. 각 정점을 `(x, y, z)`로 펼쳐 `Float32BufferAttribute`(itemSize 3)로 `position`에 설정한다. 정점 목록이 바뀌면 재빌드한다.
- **주의**: 방어적 복사로 호출자 배열과 내부 상태를 분리한다(기존 `FaceMesh` 선례).
- **인수기준**: 정점 N개를 주면 `geometry.attributes.position.count === N`. i번째 정점의 position이 `(xᵢ, yᵢ, zᵢ)`와 같다(`toBeCloseTo`). `z`가 0이 아닌 정점도 그대로 반영된다(2D 데모와의 핵심 차이).

### 기능: 수동 삼각형 면 → index 버퍼
- **의도**: 3D에선 면 연결이 자동이 아니다. 사용자가 정점 3개를 골라 삼각형을 정의하고, 그 조합들이 곧 `index` 버퍼다.
- **방식**:
  - `addFace(a, b, c)`: 정점 인덱스 3개를 받아 면 목록(`[number, number, number][]`)에 추가하고 재빌드한다. index 버퍼는 면 목록을 평탄화(`[a,b,c, …]`)한 것.
  - `removeFace(k)`: k번째 면 제거. `getFaces()`: 면 목록 복사본 반환.
  - **검증**: 아래 중 하나면 면을 추가하지 않는다(index 불변) — ① 인덱스가 정수가 아니거나 범위 `[0, vertexCount)` 밖, ② 세 인덱스 중 둘 이상이 같음(축퇴 삼각형), ③ 같은 **무순서** 3정점 조합의 면이 이미 있음(중복). 검증은 통과하되 저장은 **원래 순서(winding)를 보존**한다(법선 방향이 사용자 클릭 순서를 따르도록) — 중복 판정만 무순서로 한다.
- **주의**: 세 정점이 공선(면적 0)인 삼각형은 렌더 시 사라지지만 오류는 아니므로 막지 않는다(주석으로만 남긴다). 인덱스 검증은 정점 수 기준이라, 정점을 지우면 그 정점을 참조하던 면도 정리돼야 한다(아래 '정점 편집' 참고).
- **인수기준**:
  - `addFace(0, 1, 2)`(정점 3개 이상 존재) 후 `geometry.index`의 배열이 `[0, 1, 2]`이고 `index.count === 3`.
  - 서로 다른 면 2개를 추가하면 `index.count === 6`, `getFaces().length === 2`.
  - 범위 밖 인덱스(`addFace(0, 1, 99)`)·반복 인덱스(`addFace(0, 1, 1)`)·이미 있는 조합(순서만 다른 `addFace(2, 1, 0)`)은 **무시**되어 `getFaces().length`가 늘지 않는다.
  - `removeFace(0)` 후 해당 면이 사라지고 index가 재계산된다.

### 기능: 법선 계산 (조명 대응)
- **의도**: `MeshStandardMaterial`이 조명을 받으려면 법선이 필요하다. 3D라 면마다 법선 방향이 다르다.
- **방식**: position·index를 채운 뒤 `geometry.computeVertexNormals()`를 호출한다. 재질은 사용자가 정한 winding이 뒤섞일 수 있으므로 `side: THREE.DoubleSide`.
- **주의**: 정점을 공유하는 인접 면의 법선은 평균된다(부드러운 셰이딩). 면이 없으면(index 비어 있음) 법선도 의미 없다.
- **인수기준**: 면을 하나 이상 만든 뒤 `geometry.attributes.normal`이 존재하고 `count`가 정점 수와 같다. 정점 3개로 만든 단일 삼각형(예: xy평면 CCW)에서 각 정점 법선이 그 삼각형의 면 법선 방향과 일치한다(`toBeCloseTo`, 부호는 winding 의존).

### 기능: 작업 평면 정의 + 정점 스냅 배치 (`workPlane.ts`)
- **의도**: 2D 마우스로 3D 깊이를 정하는 문제를, 활성 작업 평면으로 깊이를 고정해 푼다. 클릭 광선이 활성 평면과 만나는 점이 곧 새 정점 좌표다.
- **방식**:
  - `workPlaneFor(key)`: `'ground' | 'front' | 'side'` → `THREE.Plane`. 바닥 `ground`=법선 `(0,1,0)`·상수 0(평면 `y=0`), 앞 `front`=법선 `(0,0,1)`·상수 0(`z=0`), 옆 `side`=법선 `(1,0,0)`·상수 0(`x=0`).
  - `placeOnWorkPlane(key, ray)`: `THREE.Ray`와 활성 평면의 교차점(`ray.intersectPlane`, 순수 계산)을 `Vector3`로 반환. 광선이 평면과 평행하거나 뒤쪽이면 `null`.
- **주의**: 세 평면 모두 원점을 지난다(상수 0) — 이번 범위에선 오프셋 평면(예: `y=3`)은 없다. 교차 판정은 THREE의 순수 수학이라 WebGL 없이 jsdom에서 테스트된다.
- **인수기준**(순수 계산, `workPlane.test.ts`):
  - `workPlaneFor('ground')`의 법선이 `(0,1,0)`, 상수 0. `front`·`side`도 각각 기대 법선.
  - 바닥 평면 위에서 아래로 쏜 광선(원점 `(2,5,3)`, 방향 `(0,-1,0)`)의 `placeOnWorkPlane('ground', ray)`가 `(2,0,3)`에 가깝다(`toBeCloseTo`, `y≈0`).
  - 평면과 평행한 광선은 `null`을 반환한다.

### 기능: 면 에지 시각화 (와이어프레임)
- **의도**: 어떤 정점들이 어떻게 이어져 면을 이루는지 눈으로 봐야 학습이 된다. 각 삼각형의 세 변을 선으로 그린다.
- **방식**: `FaceMesh3D.getFaceEdges()`가 면 목록의 각 삼각형 3변을 **중복 제거한 무방향 정점 인덱스 쌍**(`[a, b][]`)으로 반환한다. 인접 면이 공유하는 변은 하나로 합쳐진다. 페이지는 이 에지로 `LineSegments`를 그린다(기존 `FaceMesh.getTriangleEdges()` 선례와 동일한 형태).
- **주의**: 면이 없으면 빈 배열.
- **인수기준**: 사면체(정점 4개, 삼각형 면 4개)를 구성하면 `getFaceEdges()`가 **6개**의 무방향 에지를 담는다(중복 없음). 각 에지 인덱스가 실제 면의 변과 일치한다. 면이 없으면 빈 배열. **[사람 확인 필요]** 화면에서 각 삼각형의 경계선이 보인다.

### 기능: 정점 편집 (add / move / remove / reset)
- **의도**: 3D 공간에 정점을 추가·이동·삭제하며 도형을 다듬는다. 삭제는 그 정점을 쓰던 면까지 정리해야 index가 깨지지 않는다.
- **방식**:
  - `addVertex(x, y, z)`: 목록 끝에 추가 후 재빌드(면 목록은 유지 — 새 정점은 아직 어느 면에도 안 속함).
  - `moveVertex(i, x, y, z)`: i번째 좌표 갱신 후 position·normal 갱신. 면 연결(index)은 그대로다(정점 위치만 바뀜) — 2D 들로네와 달리 재삼각분할이 없다.
  - `removeVertex(i)`: i번째 정점을 제거하고, **그 정점을 참조하는 모든 면을 삭제**한 뒤, 남은 면들의 인덱스 중 `i`보다 큰 것을 **1씩 감소**시켜(정점 배열 시프트 보정) 재빌드한다.
  - `reset()`: 정점·면 모두 비운다.
- **주의**: `removeVertex`의 인덱스 재매핑이 이 기능의 핵심 난점이다 — 보정을 빠뜨리면 잘못된 정점을 가리키는 면이 남는다. `moveVertex`는 정점 수·면 연결이 불변이라 index를 유지한다.
- **인수기준**:
  - `addVertex` 후 `position.count`가 1 증가하고, 기존 면 목록은 그대로다.
  - `moveVertex(i, x, y, z)` 후 i번째 position이 `(x, y, z)`로 바뀐다(`toBeCloseTo`). 면 목록(`getFaces()`)은 불변.
  - 정점 4개·면 `[0,1,2]`,`[1,2,3]`이 있을 때 `removeVertex(0)`을 하면: 정점 0을 쓰던 면 `[0,1,2]`가 사라지고, 남은 면 `[1,2,3]`은 인덱스가 보정돼 `[0,1,2]`가 된다. `getFaces()`가 `[[0,1,2]]`.
  - `reset()` 후 `position.count === 0`, `getFaces().length === 0`, index 비어 있음.

### 기능: 페이지 상호작용 (궤도 회전 · 평면 전환 · 정점 배치 · 3점 선택으로 면 만들기)
- **의도**: 3D 공간을 돌려 보며 정점을 배치하고, 정점 3개를 골라 면을 붙여 도형을 완성하는 과정을 눈으로 본다.
- **방식**:
  - `PerspectiveCamera` + `OrbitControls`로 궤도 회전·확대(2D의 정투영 top-down과 대비되는, 진짜 3D 관찰).
  - **작업 평면 토글**: 바닥/앞/옆 버튼으로 활성 평면을 바꾸고, 활성 평면을 `GridHelper`(또는 반투명 면)로 표시한다.
  - **모드 토글**: '정점 추가' 모드에서 빈 곳 클릭 → `placeOnWorkPlane(활성평면, ray)`로 좌표를 구해 `addVertex`. '면 만들기' 모드에서 정점(마커)을 **3번 순차 클릭** → 모이면 `addFace`로 삼각형 생성(선택 하이라이트 표시, 3개 미만이면 대기).
  - 정점은 `Points`, 면 에지는 `LineSegments`(`getFaceEdges()`), 면은 반투명 `MeshStandardMaterial`로 시각화한다.
  - `reset` 버튼, 현재 정점 수·면 수 표시, 현재 모드·활성 평면 표시.
- **주의**: 정리 시 geometry·material·헬퍼·컨트롤(`OrbitControls.dispose()`)을 dispose하고 리스너를 해제한다(기존 페이지 cleanup 규약). 정점 마커 클릭 판정은 화면 투영 거리 또는 `Raycaster`의 `Points` 교차로 한다.
- **인수기준**: **[사람 확인 필요]** ① 마우스로 궤도를 돌려 3D로 관찰된다. ② 바닥/앞/옆 평면을 전환하면 그 평면 위에 정점이 찍힌다(서로 다른 깊이의 정점 생성). ③ '면 만들기' 모드에서 정점 3개를 고르면 삼각형 면이 생기고, 이를 반복해 사면체·상자 같은 **닫힌 3D 도형**을 만들 수 있다. ④ `reset`으로 모두 지워진다.

## 사람 확인 필요 (육안)
렌더링·궤도 회전·평면 전환·정점 클릭 배치·3점 선택으로 면이 붙는 상호작용·닫힌 도형 완성은
WebGL이 필요해 jsdom에서 검증 불가 → `npm run dev`로 `/vertex-face-3d`에서 육안 확인한다.
순수 계산(정점→position(z 포함), 수동 면→index 및 검증, 법선, 작업 평면 정의·광선 교차 배치,
면 에지 구성, add/move/remove(인덱스 재매핑 포함)/reset 상태 변화)만 자동 테스트한다.
